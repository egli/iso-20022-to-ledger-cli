#+TITLE: ISO 20022 to ledger-cli

Convert [[https://en.wikipedia.org/wiki/ISO_20022][ISO 20022]] (camt.053/camt.054) bank statements to csv, ready
for import into [[https://hledger.org][hledger]] or any other [[https://www.ledger-cli.org][ledger-cli]] import tool.

Obviously this goes without saying: This software is provided "as is"
without warranty of any kind. If your ledger statements are incorrect
and you believe you found a bug in the converter please file an issue
or even better a pull request.

* Usage

#+BEGIN_SRC shell
xsltproc camt-to-csv.xsl statement.xml > statement.csv
hledger import statement.csv --rules camt.rules
#+END_SRC

The csv has one row per entry, sorted by booking date, with the
columns
=date,value-date,amount,currency,reference,description,counterparty,iban,message,balance=.
Batch entries (several payments booked as one entry) get one row per
payment. =counterparty= and =iban= are the other party of the payment
and =message= is the payment message, when the bank provides them.
Debits are negative. The closing balance of the statement is in the
=balance= column of the last row, which hledger checks as a balance
assertion. If the statement is imported into a journal that doesn't
contain the balance up to the start of the statement, that check
fails; use =-I= to skip it.

Adapt =account1= in =camt.rules= to your bank account. hledger books
the other side to =expenses:unknown= or =income:unknown=; add =if=
blocks to =camt.rules= to assign accounts (see the [[https://hledger.org/hledger.html#csv][hledger csv docs]]).

* Requirements

=xsltproc= (package =xsltproc= on Debian/Ubuntu, preinstalled on
macOS).
